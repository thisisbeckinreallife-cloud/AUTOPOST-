Card:        bg-white + border-zinc-200 + shadow-sm + rounded-xl

// Texto
text-primary:   #1D1D1F  // títulos, valores
text-secondary: #48484A  // descripciones
text-muted:     #6B6B6E  // metadatos

// Focus (WCAG AA)
focus-visible: ring-2 ring-zinc-900/30 ring-offset-2

Qué contiene este bloque

Añadir success/warning/error/info/neutral con 4 tintas cada uno al theme.extend.colors de tailwind.config.ts. Usar bg-success-100 en vez de bg-green-100. Linter custom que avise si aparece green/amber/red/blue/emerald directo en src/.

Añadir text-primary/secondary/muted como utility. Grep #86868B, #48484A, #1D1D1F en src/ — debe quedar cero. Todo por clase Tailwind.

Tres niveles: shadow-xs (1px), shadow-sm (default cards), shadow-md (elevated / hover), shadow-lg (modals / dropdowns). Reemplazar los shadow-[0_0_20px_rgba(...)] custom que están en varios archivos.

Los text-xs a text-5xl de Tailwind con line-heights custom: text-sm → leading-5, text-base → leading-6, text-2xl → leading-tight, etc. Ya los usamos pero no están documentados.

Un markdown corto (2-3 páginas) con los recipes de arriba + ejemplos del JSX exacto que usamos en Ola 1-2. Cuando un desarrollador añada un componente nuevo, copia del recipe en vez de inventar clases.

Los 6 cambios

1
Rango de fechas seleccionable

Pills Hoy / 7d (default) / 30d / YTD como los de /logs. Persiste en URL.

2
KPI strip con Δ vs. periodo anterior

Cada card muestra valor + flecha coloreada con cambio % respecto al periodo inmediatamente anterior del mismo tamaño.

3
Gráfico principal: arreglar + mejorar

Barras apiladas por día (verde/rojo/amarillo por estado). Tooltip con detalle por día. Axis Y escalable.

4
Breakdown por tipo de contenido

Donut: REEL / IMAGE / CAROUSEL con % y cantidades. Insight text: "Los reels son el 62% de tus posts".

5
Tabla "Por cuenta" ordenable

Columnas: Cuenta · Publicados · Tasa éxito · Último post · Sparkline 7d. Click en cualquier columna ordena.

6
Exportar CSV del rango

Botón top-right. CSV con todas las columnas + breakdown + per-account. Respeta el rango seleccionado.

💡
Librería de gráficos

Evitar Chart.js o Recharts (peso + configuración). Usar Tremor (ya basado en Tailwind) o barras CSS puras para el gráfico principal. Sparklines: SVG inline sin dependencias.

Export CSV — 3 superficies

L

/logs

CSV con filtros aplicados (categoría, rango, búsqueda). Columnas: fecha, acción, cuenta, entidad, entityId completo, payload JSON.

M

/metrics

CSV del rango seleccionado. Incluye KPIs + breakdown por tipo + tabla por cuenta. Ideal para report a stakeholders.

P

/posts de una cuenta

CSV de todos los posts (o filtrados) con caption completo, estado, programado, publicado, permalink. Backup o análisis externo.

Generar URL pública tipo /r/report-xxxx read-only con JWT firmado que permita compartir un reporte mensual con un cliente sin darle acceso al admin. Buena feature pero opcional para Ola 3.

05

Accesibilidad WCAG AA + higiene técnica

Lo primero es que la app sea usable por cualquiera. Lo segundo es que el build log deje de vomitar warnings que enmascaran errores reales.

Accesibilidad: 7 items

F1

axe-core en npm script

Script que corre axe-core sobre las páginas admin y reporta violations. CI fallará si aparece alguna nueva.

F2

Focus visibles

Outline claro en cada botón, link, input y card clickable. Algunos hoy son invisibles.

F3

aria-label en icon-only

Navegación del calendario, cerrar lightbox, copy-ID, flechas de mes: faltan labels.

F4

role="region"

Secciones principales de cada página con aria-label. Ayuda a navegación por regiones.

F5

Contrastes auto-verificados

Herramienta que detecte ratios <4.5:1 y proponga fix. No solo a ojo.

F6

Skip link

"Saltar al contenido" como primer elemento del DOM para usuarios de teclado.

F7

Keyboard nav del lightbox

ESC cierra. Arrows cambian media entre carrusel. Trap focus mientras abierto.

Higiene técnica: 5 items

G1
Warnings de three.js (200+ líneas)

sRGBEncoding no existe en three ≥150. Actualizar @react-three/drei a ^10 o cambiar imports a SRGBColorSpace.

G2
Tipados laxos

as never en PostsPage y OR manual en /logs. Usar Prisma.PostDraftScalarFieldEnum y Prisma.AuditLogWhereInput correctamente.

G3
ECONNREFUSED de Redis en dev

Worker spamea errores si REDIS_URL no está. Mostrar sólo si está configurado, o downgrade a warning.

G4
Next.js outdated

14.2.35 → latest 14.x o evaluar subir a 15. El propio Next lo avisa en consola.

G5
npm audit

Correr npm audit fix. Revisar vulnerabilidades abiertas antes de deploy.
